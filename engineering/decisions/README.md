# Decision records

One short file per product or architecture decision: `ADR-NNNN-title.md`, numbered in order and never renamed. A decision is changed by a **new** ADR that supersedes the old one (set the old one's status to `Superseded by ADR-NNNN`). Only Ngwe decides; Claude Code proposes and drafts, and editing this folder asks permission.

Template: Date, Status, Decided by, Decision, Why, Consequences.
