# Architecture documents

- `I18N.md`: how translation works in the **live app** (Bizora Basic), rules, French typography and glossary.
- `PRO-01` … `PRO-11`: the **Bizora Pro** target architecture (domain, data dictionary, financial, local-first sync, security, analytics, services, AI, UI/UX, localization, technical). **Not yet added to this repository.** Add each file here with exactly that name when it is final.

The PRO documents describe the future product. Until a decision (an ADR in `engineering/decisions/`) says otherwise, they never change what the live Basic app does.
