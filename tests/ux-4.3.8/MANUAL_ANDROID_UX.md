# Manual UX script for a real Android phone (Bizora 4.3.8)

Use a 2 GB phone if you have one, on mobile data **and** once in airplane mode. Use the Netlify deploy preview of the release branch.
Hand the phone to someone who has never seen Bizora (a shop assistant, a relative). Say nothing. Time them; note where they pause.

| # | Task (read it aloud, nothing more) | Target | Time | Pauses / errors | Pass |
|---|---|---|---|---|---|
| 1 | Open the app and set up "your shop" | under 60 s | | | |
| 2 | Add 3 products | under 20 s each | | | |
| 3 | Sell 2 of one product for cash | under 10 s | | | |
| 4 | Send that receipt to a customer on WhatsApp | under 15 s | | | |
| 5 | Sell on credit to a new customer, with a deposit | under 20 s | | | |
| 6 | Find out how much that customer owes | under 10 s | | | |
| 7 | The customer pays part of it by Mobile Money | under 15 s | | | |
| 8 | Add an expense (transport, 1,000) | under 10 s | | | |
| 9 | How much did the shop sell today? | under 5 s | | | |
| 10 | Turn on airplane mode and repeat 3, 5, 8 | works | | | |
| 11 | Switch to French; repeat 3 | no English left | | | |
| 12 | Make a backup, then restore it on a second phone | data identical | | | |

Also note, outdoors in sunlight: can the numbers be read? One-handed with the thumb: can every button be reached?
Startup from a cold start (app closed): seconds until usable. Memory: after 30 minutes of use, does the phone slow down?

Record: phone model, Android version, RAM, browser, connection, date, tester, and a photo of anything confusing.
Any task over twice its target, or any pause over 5 s, becomes a backlog item.
